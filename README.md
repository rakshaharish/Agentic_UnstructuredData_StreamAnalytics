#  🌟 Agentic Unstructured Data Stream Analytics
Enterprise-grade, event-driven multi-source data ingestion pipeline with AI Agent orchestration.

This project leverages an AI Data Synthesizer (Agent-1) to push polymorphic credit card transactions (graph data, document data and key-value data sources) into a multi-topic Kafka broker, processes continuous micro-batches using Apache Spark Structured Streaming, and utilizes a stateful LangGraph AI Consumer (Agent-2) to enforce schema definitions and build a curated, structured historical layer. The entire system is monitored via Streamlit frontend and orchestrated via Apache Airflow, and is containerized using docker-compose.

##  ✨ Concepts & Technologies
1. Python - Development Programming Language
2. Graph Data (neo4j), Key-Value Data (redis), Document Data (mongo) - Types of unstructured data ingested in the project
3. LangChain, LangGraph - AI agent development

🚀 Execution Steps

1. Environment Preparation: Before running the project, run the below commands in the project folder to create and activate python virtual environment.
```text
bash
>> cd C:\Users\raksh\Documents\Agentic_UnstructuredData_StreamAnalytics
>> python -m venv .venv
>> .venv\Scripts\Activate.ps1
>> cd data_agent_pipeline
```

2. Install all Python requirements locally:
``` text
bash 
>> pip install -r requirements.txt
```

3. Execute Spark Stream Pipeline: To launch the PySpark consumer loop listening to your background topics.
```text
bash
>> python -m src.streaming.spark_transformer  
```

5. Expose Dashboard Interface: In a new terminal, redo Step-1 and then run the main Streamlit frontend panel.
```text
bash
>>  python -m streamlit run src/app/Streamlit_UI.py
```

4. The UI Streamlit Dashboard will open on "http://localhost:8501/". Here you can follow the next steps to execute the Stream Ingestion/Processing.
   
5. Click on "Boot Infrastructure Setup" button in the dashboard to check if the docker-container for the project is up and running to support Kafka streaming.

6. To initialize Streaming Transformers: Click "Execute Spark Stream Pipeline" button to launch the PySpark consumer loop listening to your background topics. (NOTE: This step is optional if cmd line initiation is done for the "spark_transformer.py" code)

8. Synthesize & Push Transactions: Choose the type of Source data you want to generate with the LLM model (Graph neo4j data / Key-Value Redis data / Document MongoDB data) from the drop-list under the "Agent-1" section of the dashboard and then click on "Synthesize & Route Event" button. This triggers Agent 1 (synth_agent.py) to build a high-fidelity transaction payload and distribute it to the multi-model producers. Once you do this, you can temporarily view the source data payload structure that will be ingested.

10. Enforce Schema Rules via AI: Under the "Agent-2" section of the UI dashboard, click on "Run Consumer AI Agent Loop" button to manually prompt Agent 2 (ai_agent.py) to parse, audit, and clean the landing records into your structured analytical reporting table layer, which is landed in the "structured_history.csv" file after appending the transaction timestamp. Once the Agent-2 consumes the input payload and enforces schema, it also shares the insights generated by the LLM model on the data under the "Compliance Inspection Log Output" section.

11. Finally to view the cleansed data, click on "Sync Display Channels" button under the "Data Lake Store Visualizations". This will display the 15 latest ingested & cleansed records present in the datalake.  

12. Production Workflow Scheduling: Place the dags/ module folder inside your active Airflow repository directory path to run the data collection and auditing steps automatically every hour.
